# AgentCore project config

This folder was generated by the AgentCore CLI (`agentcore create --no-agent`), and the runtime was registered with:

```bash
agentcore add agent --name ClinicalEvidenceAgent --type byo --build CodeZip \
  --language Python --framework Strands --model-provider Bedrock \
  --code-location . --entrypoint agentcore_app.py
```

`--framework` is required by the CLI for BYO agents but adds no Strands code. After registering, the runtime was pinned to `PYTHON_3_12`, and `PROVIDER_MODE` / `ARTIFACT_DIR` env vars were added in `agentcore.json`.

- `agentcore.json`: the project spec. Edit through the CLI where possible; `agentcore validate` checks it. Renaming a resource destroys and recreates it.
- `aws-targets.json`: deployment account and region. Gitignored; copy it from `aws-targets.example.json`.
- `cdk/`: generated CDK app. Run `npm install` here once; do not hand-edit the stack.
- `.llm-context/`, `AGENTS.md`: CLI-provided schema reference.

Because `codeLocation` is the repo root, the whole repo is zipped; the CLI leaves out this folder, `.venv`, `node_modules` and `.env*` files. Dependencies for the package come from the root `pyproject.toml`.

Keep AgentCore imports in `agentcore_app.py`. Domain code must not import the AgentCore SDK.
